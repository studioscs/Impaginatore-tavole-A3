# MarchioQualita

Piastra bianca per il marchio Certiquality UNI EN ISO 9001:2015 su qualsiasi fondo.

- **Struttura:** `.scs-cert` (bianco, filetto `line`) con l'`<img>` di `assets/Logos/cqy-iso-9001.png`.
- **Dove:** testata tavola (`.scs-hdr-cert`), copertina slide (`.scs-slide-cert`), ultima pagina di relazioni e offerte.
- **No:** ricolorare, ritagliare, stirare; usarlo in presentazioni di attività non coperte dal certificato; affiancarlo a marchi di altri enti senza separazione.
