# PieDiTavola

Fascia inferiore della tavola con committente, oggetto, raggruppamento, normativa e numero pagina.

- **Struttura:** `.scs-foot` > `.scs-fcell` (etichetta + valore) ripetute; l'ultima `.scs-fcell.scs-fpg` su `cqy-navy` con il numero in `.pg`. Sotto, la `.scs-band` bicolore chiude la tavola.
- **Il consumatore fornisce:** committente e settore, oggetto con CUP, composizione RTP (mandataria per prima), riferimenti normativi, numero tavola.
- **No:** più di cinque celle; testi su due righe — abbreviare.
